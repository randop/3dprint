# Incident Report – EasyThreed K9 Wall Print Quality

**Report ID:** PQ-2026-09-05-001

**Date:** 2026-09-04

**Printer:** EasyThreed K9

**Reported by:** Randolph

## Summary
Print exhibited poor wall quality (rough / inconsistent line width, weak wall-to-skin bonding) while top and bottom surfaces printed cleanly.

## Symptoms
- Top and bottom (skin) surfaces: clean, well-formed
- Vertical walls: messed up — rough, inconsistent, appearing to gap or fail to bond with adjacent skin layers

## Diagnosis
Symptom pattern (clean skin, poor walls) points to a **flow / line-width mismatch** rather than a mechanical issue (belts, backlash, ringing). Likely cause: K9's weak/underpowered extruder motor and 24 W PSU under-extrude on single-pass wall lines, while multi-pass skin infill masks the same under-extrusion.

## Ruled Out
- Wavy/wobbling walls (belt or backlash issue)
- Seam blobs (Z-seam setting issue)
- Layer shifting (belt slip)
- Ringing/ghosting (frame flex, speed/accel)

## Corrective Actions (Cura Settings)
| Setting | Change |
|---|---|
| Flow | 100% → 103–105% |
| Wall Line Width | Confirm = 0.4 mm (matches nozzle) |
| Skin Overlap Percentage | Increase to 10–15% |
| Wall Ordering (Inset Direction) | Set to Inside Out |
| Infill/Wall Overlap Percentage | Increase to 15–20% |

## Next Test
Print a calibration cube with Flow = 104%, all other settings unchanged. Evaluate whether wall-to-skin gap closes.

## Status
**Open** — awaiting test print results for validation.
